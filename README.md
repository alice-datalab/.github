## About

Alice는 여러 서비스가 공통으로 사용하는 기반 플랫폼입니다.

공통 인증, 권한 관리, 데이터 관리, 알림, 결제, 실시간 통신 등 서비스 개발에 필요한 인프라를 제공합니다.
